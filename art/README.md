# art/

Única pasta do repositório onde imagens e áudio podem ser versionados. Ela guarda **arte
original do projeto**: ícones, elementos de interface e outros arquivos criados para o
SoulSilver Desktop.

Nada extraído ou derivado da ROM pode entrar aqui: sprites, tiles, músicas e sons do jogo vêm
do extrator e ficam na pasta de dados do usuário ou em `assets/`, que não é versionada
(constituição, princípio II).
